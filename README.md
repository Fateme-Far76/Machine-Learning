# Machine Learning Assignment Repository

Welcome to the Machine Learning Assignment Repository! This repository contains my submission for the machine learning course assignment at Hanze university of Applied Sciences. In this assignment, I have implemented and evaluated various machine learning models and techniques.

 
## Files and Directories

`data/datasets/DS3/`: This directory contains the datasets used for the assignments.

## Dependencies

The following libraries were used in the implementation of the machine learning models:

- pandas
- sklearn
- numpy
- matplotlib

Please make sure to install these libraries before running the code.
